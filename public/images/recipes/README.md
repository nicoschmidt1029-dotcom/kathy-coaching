# Recipe photography

Recipe images use stable 4:3 WebP assets referenced from `lib/recipes.ts`.

The current collection is temporary generated photography. The published
Mediterranean bowl uses `mediterranean-chicken-bowl-natural.webp`, created
with a restrained home-table direction rather than a styled campaign look.

Katarina's real food photographs should replace generated images whenever they
are available. She can do this through the Admin image uploader without using
filenames or code. The website provides consistency through its 4:3 crop,
rounded corners, spacing and responsive image delivery; her food itself does
not need to be staged identically.
